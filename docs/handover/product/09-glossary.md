# 09 · Glossary

| Term | Meaning |
|---|---|
| **Brew** | The product. Never "ShopOS" (that's the team's name). |
| **Read** | Brew's live reading of a brand's public presence: store, catalog, reviews, ads, rivals, site, AI answers, socials, company facts |
| **Check what we read** | The screen where the brand corrects the read before the moves are written. Confirming claims the brand. |
| **Ledger** | The list of every fact Brew knows, each with its source. Numbers on cards must come from it. |
| **"To confirm"** | A number or claim Brew couldn't source. It's shown that way, never invented. |
| **Brief (brand brief)** | The long summary of what Brew knows about the brand, written before the moves |
| **Move** | A long strategy document (why, what we found, the plan, examples, measures), with a PDF. Core moves are 01–50; more come from listening, festivals and research gaps. Weekly moves are 1001+. |
| **Listening move / automation move** | Weekly moves: from what people say online, or routines written as plans the team runs |
| **Feed** | The ranked stream of cards for a brand and a view |
| **Card** | One idea in the feed, with a source line, a plan, often a first draft, and an action that opens a jam |
| **View / seat** | A role filter (Founder, Ads, Storefront, Retention…) that decides which cards a person sees |
| **Heard** | Cards from listening: themes people talk about, and open questions with "reply as the brand" |
| **Ideas** | Ready-to-post ideas per platform, with where to post |
| **Stories / rings** | The 24-hour circles at the top: Brand today, Trends, Popular ads, Industry news, How to |
| **Watcher** | A background check that posts cards when something changes (price, stock, AI answers, own ads) |
| **Static** | A finished ad image made around the real product photo |
| **Margin note** | A short note on a card |
| **First draft** | A ready image, carousel, video, voice or text made for a card before anyone opens it |
| **Jam** | The studio where the team shapes one card's work with AI |
| **Composer** | The jam's message box, with attachments, the model choice (Deep / Fast) and the image model |
| **Brand memory** | One shared memory per brand that every jam uses |
| **What your team told Brew** | Goals and facts Brew learned from pasted call notes or emails |
| **What Brew learned** | Lessons and rules from how the team works in jams |
| **Share the brief** | The end of a jam: copies the brief (BR-n) and a read-only link. Nothing is sent. |
| **BR-n** | The number of a shared brief |
| **Work board** | Every jam and its stage, ending at "Brief shared" |
| **Dummy** | A simulated feature, shown with a dashed tag |
| **Demo site / sandbox** | demo.joinsquareup.com: each visitor gets a private copy of a prepared brand |
| **Brand pack** | Everything Brew stores about one brand (engineering term) |
| **Claim** | Becoming the brand's owner by signing in with a work email at its domain |
| **Pro** | A simulated plan (Dummy) |
| **treg** | Our paid data service for search, ads, AI answers and social data |
